# CodeAlpha Hangman Game 🎮

## 📌 Project Overview
This project is a console-based Hangman Game developed using Python as part of the CodeAlpha Python Programming Internship.

In this game, the computer randomly selects a word from a predefined list, and the player tries to guess the hidden word by entering one letter at a time. The player can make a maximum of six incorrect guesses.

## ✨ Features
- Randomly selects a word from a predefined list.
- Allows the player to guess one letter at a time.
- Displays correctly guessed letters.
- Tracks the number of incorrect guesses.
- Prevents repeated guesses from counting again.
- Validates user input.
- Displays a winning message when the word is guessed correctly.
- Displays the correct word when the game ends.

## ▶️ How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run the following command:

```bash
python hangman.py
```

If the command does not work, try:

```bash
py hangman.py
```
